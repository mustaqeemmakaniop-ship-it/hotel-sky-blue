# Hotel Sky Blue — Clean, Simple & Family-Friendly Website 🌿🌊

Hotel Sky Blue (Adajan, Surat) ke liye ek **natural, family-friendly, professional aur simple website** jisme **zero bloatware aur zero gradients** hain. 
Faltu ka heavy custom code hata kar standard, reliable libraries (**Bootstrap 5.3.3** aur **FontAwesome 6**) ka use kiya gaya hai.

---

## 🎨 Exact Solid Colour Palette (Strictly Zero Gradients)

Budget-conscious travellers aur families ke liye clean, welcoming aur trustworthy theme:
- **Primary Teal Green:** `#287F86` (Primary action buttons, brand icons, key links, focus rings)
- **Main Warm White Background:** `#FAFCFD` (Body background, clean natural feel)
- **Soft Sky Blue Accent:** `#DCEFF7` (Section alternating backgrounds, secondary action buttons, pills)
- **Dark Slate Text:** `#263746` (Headings, body copy, high contrast readability)
- **Pure White Cards:** `#FFFFFF` (Room cards, modal surfaces, form containers)
- **Deep Teal Footer:** `#20343B` (Footer background, hero base)
- **Light Borders:** `#DDE4E8` (Card borders, input outlines, dividers)

---

## 🛠️ Used Standard Libraries & Architecture

1. **Bootstrap 5.3.3 (CSS & Bundle JS)**:
   - **Responsive Navbar**: Pure white with teal brand badge and dark slate links.
   - **Standard Modals**: Native `bootstrap.Modal` API for clean booking popups and digital vouchers.
   - **Solid Responsive Grid & Cards**: Clean `container`, `row`, `col-md-6`, `col-lg-3`, `card` layout.
   - **Solid Colours Only**: Linear & radial gradients completely prohibited.

2. **FontAwesome 6**:
   - Clean, lightweight vector icons.

3. **Google Fonts (Plus Jakarta Sans)**:
   - Modern, simple, ultra-readable typography.

## 📲 Booking & Voucher Flow

1. **Instant WhatsApp to Hotel Desk (+91 98241 21554)**: "Book Now" submit karte hi complete structured booking details Hotel Sky Blue ke reception desk WhatsApp par automatically open ho jati hai.
2. **Customer Voucher on Screen**: Customer ko instant digital voucher slip milti hai jise wo 1-click me **Save / Download** ya print kar sakte hain.
3. **Strict 1-Page Printable Voucher**: Voucher print preview A4 page par bilkul fit baithta hai (background website hide ho jati hai, zero extra blank pages).
4. **Manage Booking**: Booking reference ID ya phone number se apni past booking search aur review karne ka option.
